布丰投针可视化动画

通过随机投针实验，观察“投针与平行线相交”的频率，并用实验结果估计圆周率 π。

投针实验区

当针长 L ≤ 线距 d 时
P(相交)= 2L πd ，所以  π≈ 2LN dH
每次随机给出针的中心位置和角度。若针跨过任意一条平行线，则记为“相交”。投针次数越多，估计值通常越接近 π。

1. 随机位置

针的中心随机落在平行线之间，模拟一次随机投掷。

2. 随机角度

针与平行线方向的夹角随机产生，体现方向不确定性。

3. 判断相交

若针的两端跨过某条平行线，就记为一次相交。

4. 估计 π

根据相交频率 H/N，利用公式估计圆周率。

实验结果

总投针数 N 0 全部随机投掷
相交次数 H 0 跨过平行线
相交频率 H/N -- 实验概率
π 的估计值 -- 目标约为 3.1416
教学提示：当投针次数较少时，π 的估计值会明显波动；随着投针次数增加，估计值通常会逐渐稳定。
