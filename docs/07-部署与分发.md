## 一、三种运行方式，先选一种

| 场景 | 方式 | 需要什么 | 谁能访问 |
|------|------|---------|---------|
| **A. 本机演示** | 双击 `启动.bat` | 只有 Python | 只有自己 |

## 二、A · 本机演示（推荐）

### 环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Python | **≥ 3.11** | 必需。安装时勾选 "Add Python to PATH" |
| 浏览器 | Chrome / Edge 新版 | 必需 |
| Node.js | — | **不需要**（前端免构建） |
| Docker | — | **不需要**（存储用内置 sqlite3） |
| 大模型 API Key | — | **可选**，没有会自动降级 Mock 模式 |

### 步骤

```
1. 解压演示包到任意目录（路径里最好不要有空格）
2. Windows：双击 启动.bat
   Linux/macOS：bash start.sh
3. 首次运行会自动 pip install 依赖（约 1–3 分钟），之后跳过
4. 浏览器自动打开 http://127.0.0.1:8000/course/
```

**手动启动**（脚本出问题时）：

```bash
pip install -r requirements.txt
python scripts/gen_registry.py
cd backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

### 建议按这个顺序看

```
1) 原始动画 + 悬浮窗   http://127.0.0.1:8000/raw-live/
   ← 最能说明产品形态：8 个既有动画页面上挂着页宠，原文件一字未改

2) 演示课程页 + 页宠   http://127.0.0.1:8000/course/
   ← 模拟真实课程平台：划词、页内答疑、视频进度感知

3) 独立站点（9 页）    http://127.0.0.1:8000/
   ← 工作台 / 知识讲解 / 题目讲解 / 分布可视化 / 页面助手 /
      交互动画 / 运行轨迹 / 学习数据 / 架构与分工
```

### 接真实模型（可选）

```bash
# 1) 复制模板
copy .env.example .env          # Windows
cp .env.example .env            # Linux/macOS

# 2) 填入 Key（任选一个国内厂商，都走 OpenAI 兼容端点）
DEEPSEEK_API_KEY=sk-你的密钥
# DEEPSEEK_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1   # 通义
# DEEPSEEK_MODEL=qwen-plus
```

改完重启服务即生效。验证：打开 `http://127.0.0.1:8000/api/health`，
`provider.resolved` 应该是 `deepseek` 而不是 `mock`。

**没 Key 也能完整演示** —— Mock 模式会返回确定性的、内容合理的假回答，
用来演示协作流程、HITL、动画挂载完全够用，而且断网也能跑。

## 三、B · 局域网演示（让同学/老师用自己电脑打开）

适合"老师在另一个座位上想看"的场景。

```bash
cd backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

然后查自己的内网 IP：

```powershell
ipconfig | findstr IPv4        # Windows
ifconfig | grep "inet "        # Linux/macOS
# 假设得到 192.168.1.23
```

把 `http://192.168.1.23:8000/course/` 发给对方即可。

**注意**：

- 对方需要和你**在同一个 WiFi / 局域网**；
- Windows 防火墙会弹窗询问，选"允许"（或手动放行 8000 端口）：

```powershell
New-NetFirewallRule -DisplayName "伴学助手原型" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow
```

- 局域网下**不要**把 `LLM_PROVIDER` 设成 `deepseek` 后公开给很多人用 ——
  每个请求都在花你的 Token 钱。

### 让局域网用户安装油猴脚本

油猴脚本里的 `API_BASE` 默认是 `http://127.0.0.1:8000`，对方装上会连到自己的机器。
需要改成你的内网地址：

```js
// widget/probstat-assistant.user.js
var API_BASE = 'http://192.168.1.23:8000';   // 改成你的
```

改完让对方重新安装脚本。同时脚本顶部的 `@require` 地址也要一起改，否则装不上。

## 四、C · 服务器部署

> ⚠️ 上线前必须处理的三件事（当前代码**没有**做）：
> 1. **没有鉴权** —— 任何人都能调用，会话是浏览器本地 id，可伪造；
> 2. **没有限流** —— 一个脚本就能把你的 API 额度刷光；
> 3. **CORS 是 `*`** —— 见 `backend/app/main.py`，生产环境必须收窄。
>
> 这三件属于 P4 阶段的"用户系统"任务，见 `docs/05-开发计划.md`。

### 4.1 Docker（推荐的部署形态）

`deployment/` 目录当前只放了模板，需要 R5 在 P5 阶段补齐。最小可用形态：

```dockerfile
# deployment/Dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
RUN python scripts/gen_registry.py
ENV PYTHONUNBUFFERED=1
WORKDIR /app/backend
EXPOSE 8000
CMD ["python", "-m", "uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

```yaml
# deployment/docker-compose.yml
services:
  app:
    build: { context: .., dockerfile: deployment/Dockerfile }
    restart: unless-stopped
    env_file: ../.env
    volumes:
      - ../backend/data:/app/backend/data      # 学习记录持久化
    expose: ["8000"]

  nginx:
    image: nginx:alpine
    restart: unless-stopped
    ports: ["80:80", "443:443"]
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf:ro
      - ./certs:/etc/nginx/certs:ro
    depends_on: [app]
```

### 4.2 Nginx 反向代理（★ SSE 必须关缓冲）

```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.example.edu;

    ssl_certificate     /etc/nginx/certs/fullchain.pem;
    ssl_certificate_key /etc/nginx/certs/privkey.pem;

    # 静态资源与 API 都走同一个后端
    location / {
        proxy_pass http://app:8000;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # ★★★ SSE 流式端点必须单独配置，否则前端看不到逐字输出 ★★★
    location /api/chat/stream {
        proxy_pass http://app:8000;
        proxy_buffering off;          # 关键：不缓冲，否则回答会"憋"到全部生成完才出现
        proxy_cache off;
        proxy_read_timeout 300s;      # 长回答 + HITL 挂起可能很久
        proxy_http_version 1.1;
        proxy_set_header Connection '';   # 清掉客户端发来的 Connection: close
        proxy_set_header Host $host;
    }

    # HITL 恢复也是 SSE
    location ~ ^/api/hitl/.*/resolve$ {
        proxy_pass http://app:8000;
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
        proxy_http_version 1.1;
        proxy_set_header Connection '';
    }
}
```

代码里已经加了 `X-Accel-Buffering: no` 响应头（见 `api/chat.py`），
但**Nginx 的 `proxy_buffering off` 仍然必须显式配** —— 两个都要有。

### 4.3 HTTPS 与证书

```bash
# 用 certbot 自动申请（需要域名已解析到本机）
certbot certonly --nginx -d your-domain.example.edu
```

**必须用 HTTPS**，否则：
- 浏览器会拦截页面里的非安全请求；
- 用户装油猴脚本时会看到混合内容警告；
- 某些平台页面本身是 HTTPS，注入 HTTP 脚本会被直接拦掉。

### 4.4 让脚本指向你的域名

服务器部署后，油猴脚本里的两个地方要改：

```js
// widget/probstat-assistant.user.js
var API_BASE = 'https://your-domain.example.edu';
```

```js
// @require  https://your-domain.example.edu/widget/api.js
// @require  https://your-domain.example.edu/widget/pet.js
// …（其余 5 行同理）
```

改完把脚本重新发给使用者安装。

## 五、演示包的分发

### 5.1 自己打一个包

```bash
cd ProbCrew
python scripts/package.py --version 0.1.0
```

产出：

```
dist/
├── probstat-assistant-prototype-v0.1.0/      ← staging 目录（可直接拷 U 盘）
└── probstat-assistant-prototype-v0.1.0.zip   ← 分发包（约 1 MB）
```

打包脚本会做这些事：

| 动作 | 说明 |
|------|------|
| **扫描密钥** | 命中 `sk-...` 等特征就**中止打包**（不是警告）—— 密钥一旦分发出去就收不回 |
| 排除运行时数据 | `*.sqlite` 里是真实学习记录，属于用户隐私 |
| 排除构建垃圾 | `__pycache__`、`.env`、`dist/`、编辑器目录 |
| 生成 `PACKAGE-INFO.txt` | 构建时间 + 文件数 + 逐文件 SHA256 前 16 位，便于确认双方拿到同一份 |

**用假密钥验证过它会拦住**：

```
✘ 发现 2 处疑似密钥，**已中止打包**：
  _sectest/leak.py:1  疑似 OpenAI/DeepSeek 风格密钥 (sk-...)
  _sectest/leak2.js:1 疑似 AWS Access Key
```

### 5.2 收到包的人要做什么

```
1. 解压（路径避免空格与中文用户名以外的特殊字符）
2. 双击 启动.bat（Windows）/ bash start.sh（Linux、macOS）
3. 浏览器打开 http://127.0.0.1:8000/course/
```

就这三步。首次会自动装依赖。

### 5.3 包的内容

| 目录 | 内容 |
|------|------|
| `启动.bat` / `start.sh` | 一键启动（含依赖自检与安装） |
| `README.md` | 项目总览 |
| `原型声明.md` | **⚠️ 使用前必读**：已知限制、数据流向、合规提示 |
| `requirements.txt` | Python 依赖 |
| `contracts/` | 事件协议（前后端唯一约定） |
| `docs/` | 8 份文档 + 动画勘测报告 |
| `backend/` | FastAPI + LangGraph，7 Agent / 15 工具 |
| `frontend/` | 免构建前端 + 可注入 widget + 9 个页面 + 8 个动画 + 本地 KaTeX |
| `scripts/` | 启动、自检、联调、注册表生成、打包 |
| `dist/` | 不打包（避免自我嵌套） |

**包内自带 8 个交互动画**（`frontend/assets/animations/_raw/`），
所以 `/raw-live/` 解压后开箱即用，不依赖外部的 `动画` 文件夹。

## 七、故障排查

| 现象 | 原因 | 处理 |
|------|------|------|
| `python 不是内部或外部命令` | 没装 Python 或没勾 PATH | 重装 Python，勾选 "Add Python to PATH" |
| 依赖安装失败 | 网络问题 | 换镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 端口被占用 | 上一次没关干净 | 换端口 `--port 8010`，或结束占用进程 |
| 页面能开但**公式显示成 `$...$` 源码** | KaTeX 没加载 | 确认 `frontend/vendor/katex/` 存在，且是通过 `http://` 而不是 `file://` 访问 |
| **页宠不出现** | ① 后端没起来 ② 直接双击了 html（`file://`） | 看浏览器控制台；必须通过 `http://127.0.0.1:8000/...` 访问 |
| 页宠出现但**读不到页面内容** | 内容在跨域 iframe 里且脚本没进那个 frame | 见 `docs/06` §6；演示页不会遇到这个问题 |
| 回答**一次性蹦出来**、没有逐字效果 | Nginx 缓冲了 SSE | 按 §4.2 加 `proxy_buffering off` |
| `/api/health` 显示 `mock` 但我配了 Key | `.env` 位置不对 | 放在 `ProbCrew/.env`；或直接 `set DEEPSEEK_API_KEY=...` 后启动 |
| 「运行轨迹」页空的 | 运行记录存在**内存**里，重启即清空 | 正常现象，页面上也写了。问一个问题就有了 |
| 局域网用户打不开 | 防火墙 / 不在同一网段 | 见 §3 |

## 八、性能与资源

| 指标 | 实测值 | 说明 |
|------|--------|------|
| 冷启动 | 约 2–4 秒 | 含 Agent/工具自动发现 |
| 单次知识问答（真模型） | 2–4 秒 | 端到端，含检索 + 生成 + 校验 |
| 单次解题（真模型） | 3–6 秒 | 含 HITL 挂起（用户思考时间不计） |
| 内存占用 | 约 120 MB | 含 8 个分布模块 + LangGraph |
| 包体积 | 2.5 MB（压缩后约 1 MB） | 大头是本地 KaTeX（1.6 MB） |
| 并发 | **未测** | 单进程 uvicorn，多人同时用会排队。生产需要 gunicorn + 多 worker，且要注意运行注册表是进程内状态 |

**Token 成本参考**（真模型）：单次问答约 8–15 次 LLM 调用，
其中页面伴学因为要带页面上下文，prompt 更长。详见 `docs/05-开发计划.md` §四。
