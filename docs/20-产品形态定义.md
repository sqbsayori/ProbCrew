## 一、产品由两块组成，职责严格分开

```
┌─────────────────────────────┐         ┌──────────────────────────────────┐
│  ① 悬浮窗（注入到别人页面）    │         │  ② 主站（我们自己的站点）           │
│                             │         │                                  │
│  唯一职责：读屏幕上已有的内容   │  进入   │  题库 · 刷题（二步提示）· 错题本     │
│  唯一动作：就着这些内容提问     │ ──────▶ │  知识图谱 · 动画库 · 分布可视化      │
│  唯一出口：一个「进入主站」入口  │         │  学习数据                         │
└─────────────────────────────┘         └──────────────────────────────────┘
        ▲                                            ▲
        │ 只读                                        │ 所有重功能在这里
        │ 绝不写、不点、不改                             │
```

### 1.1 悬浮窗：**只读**

| ✅ 允许 | ❌ 禁止 |
|---|---|
| 读正文、标题层级、公式、表格 | **点击**页面上的任何按钮 |
| 读当前划选的文字 | 修改宿主页面的 DOM / 样式 |
| **读**视频播放进度（`currentTime`） | 控制视频播放/暂停 |
| **读**动画演到第几步 | **驱动**动画（代用户点"下一步"） |
| 跨 iframe 汇总可见内容 | 向宿主页面注入样式或遮罩层 |
| 把读到的内容带上一起提问 | 在宿主页面上叠加任何我们自己的可见元素 |

**一句话**：悬浮窗是**读者的眼睛 + 提问的嘴**，不是**操作的手**。

> ⚠️ **2026-09 补充（账号体系）**：问答类接口现在都要求登录，而悬浮窗注入在**第三方页面**上 ——
> 它的 `localStorage` 属于那个站点，**与主站不共享**。所以学生**需要在悬浮窗里再登录一次**。
> 本轮先做"面板内嵌最小登录"，下一轮可做「主站生成一次性授权码 → 悬浮窗换取令牌」。

**为什么必须这样**：注入的代码一旦修改宿主页面，就从"辅助工具"变成了
"篡改平台内容"，合规风险与调试成本都陡增（见 `docs/13` §一 的数据分级与
`原型声明.md` §5.2 的平台合规提示）。只读则始终站在安全一侧。

### 1.2 主站：功能重心

悬浮窗只提供**入口**；所有需要停留、操作、积累的功能都在主站。

| 主站模块 | 做什么 | 现有底子 |
|---|---|---|
| **首页入口壳** | 导航 + 各功能入口（本轮先做壳） | `frontend/app/` 已有 9 个展示页可改造 |
| **题库** | 概率论题目集（题干 + 标准答案 + 知识点 + 难度） | `question_bank/core.json` 10 道，**结构已就绪** |
| **刷题** | 作答、判定、**二步提示**、逐解析 | `grade_answer` 引擎已能用（含干扰项诊断） |
| **错题本** | 记录错题、按知识点归类、重做 | `learning.sqlite` 的 `qa_log` 已可用；`mastery` 表待接入 |
| **知识图谱** | 知识点网络 + 依赖关系 + 进度着色 | **从零建**（现无 DAG） |
| **动画库 / 分布可视化** | 资源与工具页 | 已有 `features/animations`、`features/visualize` |

**本轮不做**：掌握度热力图、PDF 阅读器 / 教材溯源定位。

## 二、相对旧形态改了什么

旧形态（`docs/06`、`docs/12` §一）把悬浮窗当"**能操作页面的伴学助手**"，
其中一个卖点是"**助手一边讲解，一边把动画走到对应的那一步**"。
新形态取消这个方向。

| 项 | 旧 | 新 |
|---|---|---|
| 悬浮窗定位 | 面板式助手（对话 + 产物 + 控制） | **只读探针 + 提问 + 主站入口** |
| 动画 | **驱动**动画（`anim-bridge.js` 点 `#playBtn`/`#stepBtn`） | **只读**当前进度，不驱动 |
| 页面交互 | 划词弹按钮、叠加遮罩、跨 frame 写入 | 只读汇总，不写 |
| 功能重心 | 悬浮窗 | **主站** |
| 题库 / 刷题 / 错题 / 图谱 | 不在主线 | **主站核心** |

### ⚠️ 因本修正而**作废**的内容

| 作废对象 | 位置 | 原因 |
|---|---|---|
| **驱动动画**的能力 | `frontend/widget/anim-bridge.js`（`control()` / `btn.click()`） | 违反"不控制页面" |
| `assistant.js` 里的动画控制条 | `assistant.js:340-362, 869-872` | 同上 |
| 划词弹「解释这段」**按钮**的写法 | `assistant.js` 选区交互 | 弹按钮属于往宿主页面写元素；改为只读选区、提问时带上 |
| `docs/17` 任务 **X2 中的"划词闭环"** | 任务书 | 同上，需重定义 |
| `docs/12` §二 P0 的"划词/选中 → 解释"表述 | 计划文档 | 口径改为"读选区 → 用户主动提问" |
| `docs/14` §七 与动画驱动相关的验收项 | 交接单 | 同上 |

> **注**：`anim-bridge.js` 的**只读**部分（识别这是哪个动画、演到第几步）
> **保留**，它是"我学到哪了"的数据来源。只删 `control()` 这条驱动路径。
