## 四、关键设计决策（★ 不要轻易推翻）

这些是踩过坑之后定下来的，推翻前请先读理由。

### 4.1 契约优先，只增不改

`contracts/` 是唯一约定。**新增枚举值可以，改字段名/语义不行**（要走 ADR）。
`scripts/check_contracts.py` 会拦住不一致。

> **为什么**：契约腐化的方式是"加了个字段忘了改 schema"——不报错，几周后爆发。

### 4.2 自动发现，不加共享文件

Agent / 工具 / API / 页面**全部靠目录扫描**。
新增东西 = 新增一个文件，**不改任何共享文件**。

> **为什么**：5 人并行开发时，冲突永远发生在注册表/路由表/`__init__.py`。

### 4.3 能算的不要问模型

| 问题 | 交给谁 |
|------|--------|
| 意图识别 | 规则路由（`agents/_router.py`），LLM 只兜底 |
| 期望/方差/矩母函数 | **SymPy**（`domain/distributions.py`） |
| 从提问里抽分布与参数 | 正则（`_router.extract_distribution`） |
| 组织语言 | LLM ← 这才是它的强项 |

> **为什么**：LLM 会算错，符号计算不会。

### 4.4 流式与编排解耦

Agent 不 return 给 HTTP，而是 `ctx.emit(event)` 写进 `run.queue`；SSE 端点只是消费者。

> **为什么**：单 Agent 可脱离 LangGraph 单测；换传输不影响 Agent 代码。

### 4.5 动画文件一字不改

8 个既有动画是**资产**，通过 manifest + 同源 iframe 驱动。
`/raw-live/` 路由在**响应时**注入悬浮窗，不改磁盘文件。

> **为什么**：它们要能离线、能单独分发、能塞进数字教材。

### 4.6 悬浮窗的两条硬约束

1. **必须 http 提供**：`file://` 下浏览器视为 opaque origin，读不到 iframe
2. **离开页面必须销毁 iframe**：`markov-chain` 有停不掉的 rAF 循环

### 4.7 安全性放在分支保护，不放在 token 权限

token 只有"小但不好用"或"好用但危险"两种选择；
分支保护让 token 够用而不致命。

## 五、★ 下一步：主线 M1 正确性保障链

**完整方案在 `docs/09`。这里只给"明天就能开工"的部分。**

### 核心命题

> 现在系统对"正确"的保障只有三条规则检查（步骤数 ≥3、公式定界符平衡、溯源率）。
> **那是 lint，不是验证。** M1 要建的是真正能拦住错误的链。

### 要建的链

```
形式化(NL→MathTask) → 3 路独立求解 → 交叉比对 → 逐步骤符号校验
                   → 约束检查 → 反向代入 → 存疑标注
```

### 诚实前提：不是所有题都能"确保正确"

**必须按题型分级，并且展示给用户**（这条不能妥协）：

| 级别 | 题型 | 手段 | 承诺 |
|------|------|------|------|
| **A** | 纯数值题 | SymPy 高精度重算 | 可完全验证 |
| **B** | 公式推导 | 符号等价性 | 可强验证 |
| **C** | 应用题 | 多路一致性 + 约束 + 反向代入 | 可交叉验证 |
| **D** | 证明题 | —— | **不做承诺，明确标注** |

### 建议的开工顺序

| 顺序 | 任务 | 新建文件 | 验收 |
|------|------|---------|------|
| 1 | **形式化** | `backend/app/domain/formalize.py` | 50 道题形式化准确率 ≥ 85% |
| 2 | **数值校验** | `backend/app/tools/verify_numeric.py` | 数值题 100% 走 SymPy 重算 |
| 3 | **约束检查** | `backend/app/domain/constraints.py` | 概率>1、方差<0 必须被拦 |
| 4 | **逐步骤校验** | `backend/app/domain/step_check.py` | 相邻步等价性覆盖 ≥90% 步骤 |
| 5 | **多路求解** | `backend/app/agents/` 新增 2 个策略节点 | 3 路独立求解 + 分歧报告 |
| 6 | **反向代入** | `backend/app/tools/back_substitute.py` | A 级题 100% 执行 |
| 7 | **验证报告** | `backend/app/kernel/verification.py` | 按 `contracts/verification.schema.json` |

## 六、踩过的坑（不能忘）

| 坑 | 教训 | 记录位置 |
|---|---|---|
| **dev→main 用 squash 导致历史分叉** | squash 只能用在"合并后分支就删掉"的场合；`dev` 是长期分支 | `docs/04 §4.2` |
| **`hitl.request` 没被记进轨迹** | 它只 yield 给 SSE，没 `run.emit()`。改用 `run.record()`（只留档不进队列，否则 resume 会重复读） | 代码注释 |
| **PAUSE 哨兵污染事件轨迹** | 哨兵不是事件。加了 `Run.signal()` 专供哨兵 | 代码注释 |
| **前端读 `plan.reason` 但后端从没发** | 静默失效了很久。契约校验能防这类问题 | `docs/04` |
| **选区残留劫持其他意图** | 浏览器保留选区，"我学到哪了"被误判成解释选中。加了 `NOT_ABOUT_SELECTION` + 5 个回归测试 | `_router.py` 注释 |
| **LaTeX 定界符** | DeepSeek 输出 `\(...\)`，前端只认 `$...$`。**渲染器做归一化**（防御任何模型）+ Prompt 明确要求 | 双保险 |
| **PowerShell 5.1 的 UTF-8 问题** | `Out-File -Encoding utf8` 会加 BOM，破坏 JSON 与提交信息。**用 Python 写文件** | 本文 附录 |
| **路径探测差一层** | `PROJECT_ROOT` 的 `parents[N]` 数错过两次。改动后务必验证 `/raw-live/` 能找到动画 | 已加多级回退 |
| **CPython `re` 偶发异常** | 标准库缺陷，8640 次未复现。记录在案，升级 Python 可再验 | `docs/notes/已知问题.md` |

## 十、附录：本环境的两个硬性注意

### A. PowerShell 5.1 的编码

```powershell
# ✘ 会加 BOM，破坏 JSON / git 提交信息
"..." | Out-File x.json -Encoding utf8

# ✔ 用 Python 写
python -c "import pathlib; pathlib.Path('x.json').write_text(s, encoding='utf-8', newline='\n')"
```

同理：`gen_registry.py` 和 `gen_api_contract.py` 都显式用了 `newline="\n"`，
否则 Windows 生成 CRLF、Linux 生成 LF，CI 的 `--check` 必然误报。

### B. `.gitattributes` 锁死换行符

| 文件 | 必须 |
|------|------|
| `.sh` | LF（否则 Linux 报 `bash\r`） |
| `.bat` / `.ps1` | CRLF |
| `Dockerfile` / `*.conf` | LF（**CRLF 的 Dockerfile 会构建失败**） |

改动这些文件后跑 `git ls-files --eol` 确认。
