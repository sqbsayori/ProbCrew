# 11 · 骨架剪枝清单（保留 / 删除 / 去留待定）

> **背景**：当前仓库能跑，但它是"答辩演示包"，不是"能开工的骨架"。
> 判断依据只有一条：**这份代码是产品的一部分，还是为了展示产品而存在的？**
>
> 统计口径：后端 4.7k 行 Python，前端 7.8k 行 JS + 2.5k 行 CSS（不含 vendored KaTeX 与 8 个动画）。

---

## 零、一句话结论

**产品本体只有两块**：

```
frontend/widget/**        3.2k 行  ← 这才是产品：悬浮窗 / 页宠 / 页面抽取 / 跨 iframe
backend/app/kernel/**     0.9k 行  ← 这是骨架：事件契约 / 注册表 / 编排图 / 运行态
```

其余都可以按"是否支撑这两块"来决定去留。

## 四、剪枝后的目标结构

```
ProbCrew/
├─ contracts/                 ← 不动（前后端唯一契约）
├─ backend/
│  ├─ app/
│  │  ├─ kernel/              ← 不动（骨架）
│  │  ├─ agents/              ← 保留 orchestrator / _router / page_tutor / knowledge / solver / verifier
│  │  ├─ tools/               ← 保留 kb_search / math_tools / page_tools；learning_log 暂留待定
│  │  ├─ api/                 ← 只留 chat.py（SSE）+ system.py（health）+ raw_live.py
│  │  ├─ providers/           ← 不动
│  │  └─ domain/              ← 降级为可选
│  ├─ knowledge_base/         ← 保留（结构留着，内容待换教材）
│  └─ tests/                  ← 不动
├─ frontend/
│  ├─ widget/                 ← 产品本体，全部保留
│  ├─ styles/tokens.css       ← 设计令牌（widget 也用）
│  ├─ index.html              ← 改成一个"最小宿主页"，用于本地开发调试
│  └─ examples/               ← 从 course/ 移来的示例页（不进主应用）
├─ scripts/                   ← 不动
├─ docs/                      ← 见上表
└─ 启动.bat / start.sh
```

**验收标准（剪枝完成的定义）**：

1. `python scripts/check_contracts.py`、`smoke_test.py`、`pytest`、两个 `.mjs` 测试 **全绿**
2. 删掉的文件**没有任何引用残留**（`gen_registry.py --check` 通过）
3. `git clone` → `启动.bat` → 打开 `http://127.0.0.1:8000/examples/course/`
   能在 **5 分钟内**看到悬浮窗并成功提问一次
4. 旧演示可通过 tag `v0.1.0-prototype` 找回

## 五、执行顺序（避免把仓库改坏）

1. **打 tag** `v0.1.0-prototype`（在 `main` 上，先留后路）
2. **先删前端展示页**：删 `features/*` → 修 `bootstrap.js` → 修 `index.html` →
   跑 `gen_registry.py` → 跑 `_test_mount.mjs`（**这一步最容易漏引用，测试会拦住**）
3. **再删后端展示端点**：删 `api/problems.py` `api/knowledge.py` → 重生成 `contracts/api.md` → 跑契约校验
4. **移 `course/` 到 `examples/`**，改 `启动.bat` 的提示地址
5. **删 `doc/08`、`assets/animations/_raw`**（若确认分发包另行处理）
6. **重写 `docs/00-快速开始.md`**：面向新成员，5 分钟跑起来
7. **全量验收** → PR 到 `main`

> 第 2、3 步之间**不要并发修改**：删页面会同时影响 `features.registry.js`、`bootstrap.js`、
> `index.html`、`contracts/api.md` 四处，必须一次改完再跑测试。
