## 5. 常见问题

**Q：公式显示成 `$...$` 源码？**
KaTeX 没加载成功。确认 `frontend/vendor/katex/katex.min.js` 存在，并且是通过
`http://127.0.0.1:8000` 访问而不是直接双击 `index.html`。

**Q：动画打开了但按钮点不动？**
同上，必须是 http(s) 访问。`file://` 下浏览器把 iframe 视为 opaque origin，
`contentDocument` 会被拒绝。系统已经通过后端静态目录解决了这个问题，**不要双击 html 文件**。

**Q：动画页面切走后电脑风扇还在响？**
这是 `markov-chain` 的已知特性：它的 `requestAnimationFrame` 循环写在 IIFE 闭包内，
外部无法停止。我们的播放器在 `unmount` 时会**销毁整个 iframe 节点**（不是 `display:none`）。
如果你自己写了新的嵌入方式，务必照做。

**Q：`/api/health` 显示 `mock`，但我配了 Key？**
检查 Key 的读取路径：`our-system/.env` 或 `F:\学习资料\大创\.env`（自动向上找两级）。
也可以直接 `$env:DEEPSEEK_API_KEY="sk-..."` 后再启动。

**Q：端口被占用？**
`.\scripts\dev.ps1 -Port 8080`
